# Contrôle des notes de frais

## Ce que l'on vérifie

Pour chaque note de frais reçue dans Kiosque, l'équipe comptabilité vérifie quatre points :

1. Le montant respecte les plafonds de la politique de frais.
2. Une facture lisible est jointe.
3. Un code projet valide (format PRJ-XXXX) est renseigné.
4. La dépense date de moins de 30 jours.

Si un point n'est pas respecté, la note est renvoyée au salarié avec un commentaire expliquant le motif.

## Anomalies fréquentes

- Doublon : deux notes avec le même montant et la même date. Il faut vérifier auprès du salarié avant de valider.
- Repas pris le week-end sans déplacement justifié : la note est refusée.
- Code projet clos : le projet est terminé, la dépense doit être rattachée à un projet actif.

## Date de remboursement

Les notes validées avant le 20 du mois sont remboursées avec le salaire du mois. Les notes validées après le 20 sont remboursées le mois suivant.
