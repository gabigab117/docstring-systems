# Notes de frais

## Plafonds de remboursement

Les frais engagés pour un déplacement professionnel sont remboursés dans les limites suivantes :

- Repas : 25 € par repas.
- Hôtel : 150 € la nuit à Paris, 110 € la nuit dans les autres villes, petit-déjeuner compris.
- Train : seconde classe. La première classe est acceptée si le trajet dure plus de 3 heures.

Toute dépense au-dessus du plafond reste à la charge du salarié, sauf accord écrit de son manager.

## Délai pour déclarer une dépense

Les notes de frais se déposent dans Kiosque, rubrique « Mes frais », au plus tard 30 jours après la dépense. Au-delà, elles sont refusées.

## Justificatifs

Une facture est obligatoire pour chaque dépense. Le ticket de carte bancaire seul ne suffit pas. Une photo de la facture est acceptée si elle est lisible.

## Code projet

Chaque dépense doit être rattachée à un code projet au format PRJ suivi de quatre chiffres, par exemple PRJ-2041. Le code se trouve dans la fiche du projet sur Kiosque. Une note sans code projet est renvoyée au salarié.
