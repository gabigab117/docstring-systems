# Accès aux locaux et Wi-Fi

## Les badges

Les bureaux de Lyon, Paris et Lille sont ouverts de 7 h à 20 h, du lundi au vendredi. L'entrée se fait avec le badge remis le premier jour.

En cas de perte du badge, il faut le signaler à l'accueil le plus tôt possible. Un badge temporaire est remis dans la journée, et l'ancien badge est désactivé.

## Les réseaux Wi-Fi

Deux réseaux sont disponibles dans tous les bureaux :

- `DS-Salaries` : donne accès au réseau interne. La connexion se fait avec son compte Docstring Systems.
- `DS-Invites` : donne accès à Internet uniquement, pour les visiteurs.

Le code du réseau invité change chaque lundi. Il est affiché à l'accueil.
