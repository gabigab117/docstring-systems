# Télétravail

## Combien de jours par semaine ?

Chaque salarié peut faire jusqu'à 2 jours de télétravail par semaine. Les jours sont choisis avec son manager et notés dans Kiosque, rubrique « Mon planning ».

Le mardi est un jour de présence obligatoire pour tout le monde : c'est le jour de la réunion d'équipe.

## Matériel fourni

Docstring Systems fournit un ordinateur portable à chaque salarié. Un écran supplémentaire peut être prêté pour le domicile : il suffit d'ouvrir un ticket au support informatique.

Une indemnité forfaitaire de 30 € par mois est versée avec le salaire pour couvrir les frais d'électricité et de connexion.

## Se connecter au VPN

Le VPN est obligatoire pour accéder aux outils internes depuis l'extérieur des bureaux. Le client utilisé est WireGuard.

Le fichier de configuration se télécharge dans Kiosque, rubrique « Mon poste ». Il est personnel et ne doit jamais être partagé.
